# 📱 Mobile Access - Quick Reference

## 🚀 Fastest Way to Start

### Windows Users:
Double-click: **`start_mobile.bat`**

### All Users:
```bash
python quick_mobile_start.py
```

Then scan the QR code with your phone!

## 🎯 Quick Commands

| Command | Purpose |
|---------|---------|

| `python quick_mobile_start.py` | Quick start (all platforms) |
