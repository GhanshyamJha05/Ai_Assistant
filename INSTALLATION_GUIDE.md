# AI Assistant - Windows Desktop App Installation Guide

## 📥 Quick Start

### Step 1: Download
Download `AI-Assistant-Windows.zip` from the website

### Step 2: Extract
1. Locate the downloaded ZIP file in your Downloads folder
2. Right-click on `AI-Assistant-Windows.zip`
3. Select "Extract All..."
4. Choose a location (Desktop is recommended)
5. Click "Extract"

### Step 3: Run
1. Open the extracted folder
2. Double-click `Run-AI-Assistant.bat`
3. The AI Assistant will launch in a desktop window

## 💡 Tips

### Creating a Desktop Shortcut
1. Navigate to the `AI-Assistant` folder
2. Right-click `AI-Assistant.exe`
3. Select "Send to" → "Desktop (create shortcut)"

### First Time Setup
- The app may take a few seconds to start on first launch
- Windows Defender might show a warning - click "More info" then "Run anyway"
- Grant necessary permissions when prompted

### Troubleshooting

**App won't start?**
- Make sure you extracted ALL files from the ZIP
- Try running as Administrator (right-click → Run as administrator)
- Check that you have Windows 10/11 64-bit

**"Windows protected your PC" message?**
- This is normal for new applications
- Click "More info"
- Click "Run anyway"

**Missing features?**
- Ensure you have an internet connection for AI features
- Check your firewall isn't blocking the app

## 🔄 Updates

To update to a new version:
1. Download the latest version
2. Extract to a new folder
3. Your settings and data are stored separately and will be preserved

## 🗑️ Uninstallation

To remove the app:
1. Close the AI Assistant if running
2. Delete the extracted folder
3. Remove any desktop shortcuts
